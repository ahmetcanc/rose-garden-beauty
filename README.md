# Rose Garden Beauty

Rose Garden Beauty icin hazirlanmis TanStack Start tabanli web sitesi.

## Yerelde calistirma

Node.js 20 veya daha yeni bir surum kurulu olmalidir.

```sh
cd /home/acc/Desktop/rose-garden-beauty
npm install
npm run dev
```

Terminalde gosterilen yerel adresi (genellikle `http://localhost:5173`) tarayicida acin.

## Diger komutlar

```sh
npm run build
npm run preview
npm run lint
```
